    Chrome only lets extensions list printers on ChromeOS. On Mac and Windows the way in is DYMO Connect's local web service, which lists LabelWriters and prints silently. This checks both.

    Need DYMO Connect? Free from DYMO: Windows (1.6.3) · Mac, Apple silicon (1.6.3) · all versions on dymo.com. Install it, plug the LabelWriter in by USB, then click Detect.

    On a Mac DYMO's service doesn't run reliably, so use the Showrunner Print Bridge instead (the mac-print-bridge zip on the releases page): unzip it, run start.sh, keep its window open, then click Detect.
